## Features

- Zombies render smaller (edit `SCALE` in `TinyMobsMixin.java`).
- Auto-closes the shop after "You purchased Human Cannonball!".
- Holding a Hollow Wand makes right-clicks pass through mobs.

Behaviour based on the Kittycat mod (MIT / CC0), rewritten from scratch.
